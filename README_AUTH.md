# نظام إدارة سكن العاملات - دليل الاستخدام

## 📋 المميزات الجديدة

### 1. **نظام تسجيل الدخول والأمان**
- ✅ تسجيل دخول آمن للموظفين
- ✅ إدارة المستخدمين والأدوار والصلاحيات
- ✅ تسجيل جميع الأنشطة (Activity Logs)

### 2. **إدارة المستخدمين**
- ✅ إضافة وتعديل وحذف المستخدمين
- ✅ تعيين الأدوار للمستخدمين
- ✅ تفعيل/تعطيل المستخدمين

### 3. **إدارة الأدوار والصلاحيات**
- ✅ إنشاء أدوار مخصصة
- ✅ إدارة الصلاحيات لكل دور
- ✅ 4 أدوار افتراضية:
  - **مدير النظام**: صلاحيات كاملة
  - **مشرف**: صلاحيات إدارة العاملات والمكاتب
  - **موظف**: صلاحيات محدودة (عرض وإضافة فقط)
  - **مراجع**: صلاحيات عرض فقط

### 4. **سجل الأنشطة (Activity Logs)**
- ✅ تسجيل جميع الإجراءات (إضافة، تعديل، حذف، أرشفة)
- ✅ معلومات المستخدم والتاريخ والوقت
- ✅ تتبع التغييرات (البيانات القديمة والجديدة)
- ✅ فلترة متقدمة حسب:
  - نوع الكيان
  - الإجراء
  - المستخدم
  - التاريخ

## 🚀 البدء السريع

### 1. تحديث قاعدة البيانات
قم بتشغيل `schema.sql` لإنشاء الجداول الجديدة:
```bash
mysql -u root accommodation_db < schema.sql
```

### 2. إنشاء المستخدمين التجريبيين
قم بزيارة الرابط التالي في المتصفح:
```
http://localhost/accommodation/init_users.php
```

### 3. تسجيل الدخول
استخدم بيانات المستخدم التالية:
- **المستخدم**: `admin`
- **كلمة المرور**: `admin123`

أو:
- **المستخدم**: `user`
- **كلمة المرور**: `user123`

## 📊 جداول قاعدة البيانات الجديدة

### جدول users
```sql
- id: معرف المستخدم
- username: اسم المستخدم (فريد)
- email: البريد الإلكتروني (فريد)
- password: كلمة المرور المشفرة
- full_name: الاسم الكامل
- role_id: معرف الدور
- status: حالة المستخدم (نشط/معطل)
- created_at: تاريخ الإنشاء
- updated_at: تاريخ آخر تحديث
```

### جدول roles
```sql
- id: معرف الدور
- role_name: اسم الدور
- description: وصف الدور
- created_at: تاريخ الإنشاء
- updated_at: تاريخ آخر تحديث
```

### جدول permissions
```sql
- id: معرف الصلاحية
- permission_name: اسم الصلاحية
- description: وصف الصلاحية
- module: وحدة/نوع الصلاحية
- created_at: تاريخ الإنشاء
```

### جدول role_permissions
```sql
- id: معرف
- role_id: معرف الدور
- permission_id: معرف الصلاحية
```

### جدول activity_logs
```sql
- id: معرف السجل
- user_id: معرف المستخدم
- action: نوع الإجراء (ADD, EDIT, DELETE, ARCHIVE, etc)
- entity_type: نوع الكيان (workers, offices, users, etc)
- entity_id: معرف الكيان
- old_data: البيانات القديمة (JSON)
- new_data: البيانات الجديدة (JSON)
- description: وصف الإجراء
- ip_address: عنوان IP
- user_agent: معلومات المتصفح
- created_at: تاريخ الإنشاء
```

## 🔧 الدوال المساعدة (helpers.php)

### hasPermission($permission, $pdo)
التحقق من وجود صلاحية معينة للمستخدم الحالي

### requirePermission($permission, $pdo)
إرجاع خطأ 403 إذا لم تكن لديك الصلاحية

### logActivity($user_id, $action, $entity_type, $entity_id, $old_data, $new_data, $description, $pdo)
تسجيل نشاط في جدول activity_logs

### getUserInfo($user_id, $pdo)
الحصول على معلومات المستخدم

### getUserPermissions($user_id, $pdo)
الحصول على قائمة صلاحيات المستخدم

## 🎯 كيفية إضافة صلاحية جديدة

1. أضف الصلاحية في جدول permissions:
```php
INSERT INTO permissions (permission_name, description, module) 
VALUES ('permission_name', 'الوصف', 'module');
```

2. أسند الصلاحية للأدوار المطلوبة:
```php
INSERT INTO role_permissions (role_id, permission_id) 
VALUES (role_id, permission_id);
```

3. تحقق من الصلاحية في الكود:
```php
if (hasPermission('permission_name', $pdo)) {
    // قم بالإجراء
}
```

## 🆘 استكشاف الأخطاء

### مشكلة: "ليس لديك صلاحية"
**الحل**: تحقق من أن المستخدم لديه الصلاحية المطلوبة من خلال إدارة الأدوار

### مشكلة: خطأ 403 Forbidden
**الحل**: تأكد من تسجيل الدخول أولاً، وأن لديك الصلاحية المطلوبة

### مشكلة: المستخدم لا يظهر في النظام
**الحل**: تأكد من أن حالة المستخدم "نشط" وليس "معطل"

## 📞 الدعم والمساعدة

للمزيد من المعلومات أو الإبلاغ عن مشاكل، يرجى التواصل مع فريق الدعم.
