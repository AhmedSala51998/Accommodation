🔴 المشكلة: لا يوجد مستخدمين في قاعدة البيانات!

═══════════════════════════════════════════════════════════

✅ الحل:

1️⃣ فتح Command Prompt أو PowerShell

2️⃣ انتقل إلى مجلد XAMPP:
   cd C:\xampp\htdocs\accommodation

3️⃣ شغّل schema.sql:
   mysql -u root accommodation_db < schema.sql

   أو إذا لم تعمل، جرّب:
   mysql -u root < schema.sql

   وإذا لم تعمل أيضاً، استخدم:
   C:\xampp\mysql\bin\mysql -u root accommodation_db < schema.sql

═══════════════════════════════════════════════════════════

📊 بعد تشغيل schema.sql ستُنشأ تلقائياً:

✅ 5 جداول جديدة:
   - users (المستخدمين)
   - roles (الأدوار)
   - permissions (الصلاحيات)
   - role_permissions (العلاقات)
   - activity_logs (سجل الأنشطة)

✅ 4 مستخدمين افتراضيين:

   👑 admin / admin123
      (مدير النظام - صلاحيات كاملة)

   🎯 supervisor / supervisor123
      (مشرف - إدارة العاملات)

   👤 user / user123
      (موظف - صلاحيات محدودة)

   📋 reviewer / reviewer123
      (مراجع - عرض فقط)

═══════════════════════════════════════════════════════════

🧪 التحقق:

بعد التشغيل، زيارة هذا الرابط للتحقق:
http://localhost/accommodation/check_users.php

يجب أن ترى 4 مستخدمين مدرجين ✅

🚀 بعد ذلك:

1. افتح http://localhost/accommodation/login.php
2. سجّل الدخول ب: admin / admin123
3. استمتع باستخدام النظام! 🎉

═══════════════════════════════════════════════════════════

❓ مشاكل شائعة:

❌ "MySQL command not found"
   → أضف مسار XAMPP إلى System PATH
   → أو استخدم المسار الكامل:
   C:\xampp\mysql\bin\mysql -u root accommodation_db < schema.sql

❌ "Access denied for user 'root'"
   → استخدم كلمة مرور الصحيحة (عادة لا توجد كلمة مرور)
   → mysql -u root -p accommodation_db < schema.sql

❌ "Database not found"
   → أنشئ قاعدة البيانات أولاً:
   mysql -u root -e "CREATE DATABASE accommodation_db CHARACTER SET utf8mb4"
